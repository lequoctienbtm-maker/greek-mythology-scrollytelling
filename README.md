# Greek Mythology Scrollytelling Website

Trang web kể chuyện theo phong cách tương tác Scrollytelling (cuộn chuột điều khiển hoạt ảnh) với chủ đề Thần thoại Hy Lạp cổ đại.

## Công nghệ sử dụng
- **HTML5 & Modern CSS3** (Flexbox, CSS Variables, Typography cổ điển)
- **SVG Vector Graphics** (Mây, tượng thần Zeus, Đền thờ Parthenon)
- **GSAP 3 & ScrollTrigger** (Điều khiển timeline và hoạt ảnh mượt mà khi cuộn)

## Hướng dẫn đẩy lên GitHub Pages
1. Giải nén file `.zip`.
2. Khởi tạo kho lưu trữ hoặc tải các file (`index.html`, `style.css`, `script.js`) lên GitHub Repository của bạn.
3. Vào **Settings > Pages** trong repo, chọn nguồn là nhánh `main` (hoặc `master`) rồi lưu.
4. (Tùy chọn) Thêm tên miền riêng tại mục **Custom domain** và trỏ CNAME trong trình quản lý DNS (như Cloudflare) nếu cần.
